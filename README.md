# AIGeneratedDashboard - AirtelLMS

A standalone learning operations dashboard with synthetic data, created with Codex for the AI-Assisted SDLC Assignment.

Open [the dashboard](LearnetLinq.WebUI/AIGeneratedDashboard/index.html) in Google Chrome after cloning. No installation, database, login, or web server is needed.

See [documentation](docs/AIGeneratedDashboard/README.md), [submission table](docs/AIGeneratedDashboard/SUBMISSION.md), and [test results](docs/AIGeneratedDashboard/artifacts/test-results.json).

This repository contains only dashboard runtime files, the required Airtel logo, tests, and assignment evidence. It excludes the existing AirtelLMS application and its repository history.
